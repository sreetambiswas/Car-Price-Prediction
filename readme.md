# Car Price Prediction using Machine Learning

## Overview

This project predicts the selling price of used cars using Machine Learning.

## Features

- Data preprocessing
- Label Encoding
- Feature Scaling
- Model Training
- Price Prediction
- Flask Web Application

## Technologies Used

- Python
- Flask
- Scikit-Learn
- Pandas
- NumPy
- Matplotlib

## Project Structure

```
Car-Price-Prediction/
│
├── app.py
├── model.ipynb
├── car_price_model.pkl
├── scaler.pkl
├── label_encoders.pkl
├── requirements.txt
├── README.md
├── .gitignore
└── CarPrice_Assignment.xlsx
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
